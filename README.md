**Цель проекта:**<br> 
Оценить эффективность нового формата маркетинговых уведомлений (пуш-уведомления) в приложении SkyLenta, сравнить его с баннерами, выявить влияние на конверсию в покупку и средний чек, и подготовить рекомендации для оптимизации маркетинговой стратегии.

**Методы:**<br>
Изучение структуры исходных данных и подготовка их к анализу.<br>
Очистка и объединение таблицы клиентов, заказов и регионов.<br>
Рассчёт агрегированных показателей по каждому клиенту и торговой точке.<br>
Статистический анализ результатов A/B-теста: сравнение конверсии и среднего чека между тестовой и контрольной группами с использованием t-теста и критерия Манна-Уитни.<br>
Сегментирование данных по городам и торговым точкам и повторение анализа на каждом сегменте.<br>
Подготовка итоговой таблицу-калькулятора в Excel для оценки финансового эффекта внедрения нового формата уведомлений.

**Инструменты и приёмы работы:**<br>
Python (Jupyter Notebook): работа с pandas, numpy, matplotlib/seaborn, написание функций для автоматизации анализа.<br>
Статистические методы: t-критерий, критерий Манна-Уитни, расчет p-value и интерпретация результатов.<br>
Excel: построение калькулятора с промежуточными и итоговыми расчетами, подготовка таблиц для презентации результатов.<br>
Работа с большими данными: объединение нескольких таблиц, очистка пропусков и аномалий, агрегация по клиентам и торговым точкам.

**Результат:**<br>
Подготовлена интерактивная таблица-калькулятор, демонстрирующая результаты A/B-теста на уровне торговых точек и городов.<br>
Рассчитан эффект внедрения пуш-уведомлений на средний чек и конверсию клиентов.<br>
Выявлены сегменты с положительным, отрицательным и нейтральным эффектом от нового формата уведомлений.<br>
Представлены рекомендации для руководства по дальнейшему внедрению нового формата уведомлений.<br>
Весь анализ оформлен в Jupyter Notebook и экспортирован в Excel с визуализациями и итоговыми расчетами, готовыми к презентации менеджменту.

### <br>Общее сравнение групп:

Сравнение групп проводилось по факту конверсии в платёж и по его размеру.<br> 
Для сравнения по размеру платежа использовался t-критерий (сравнение средних) и критерий Манна-Уитни (сравнение медиан).<br>
Для сравнения по факту конверсии критерий Манна-Уитни не используем, так как возможные значения для медианы тут только 0 и 1.

**Платежи, t-критерий:**
Cреднее тестовой группы: 2452.28<br>
Среднее контрольной группы: 2189.19<br>
p_value = **3.32e-21** < 0.05<br>
Основываясь на t-критерии, разница между группами статистически значима

**Конверсия, t-критерий:**
Среднее тестовой группы: 0.54<br>
Среднее контрольной группы: 0.50<br>
p_value = **1.73e-20** < 0.05<br>
Основываясь на t-критерии, разница между группами статистически значима

**Платежи, критерий Манна-Уитни:**
Медиана тестовой группы: 1669<br>
Медиана контрольной группы: **0**<br>
p_value = **3.01e-24** < 0.05<br>
Основываясь на критерии Манна-Уитни, разница между группами статистически значима

Как видим, медиана контрольной группы по выплатам = 0, хотя отрицательных значений нет. Это означает, что **более половины клиентов ничего не заплатили**.

В общем A/B-тестировании можно сделать вывод, что **у тестовой группы статистически значимо больше и конверсия в платёж, и его размер (среднее и медиана)**, так что в общем push-уведомления показывают себя намного лучше, чем баннеры, однако стоит рассмотреть результаты по каждому городу отдельно.

### <br>**Сравнение групп для каждого города:**

В городах Москва, Санкт-Петербург, Самара, Владимир - тестовая группа по всем критериям статистически значимо превосходит контрольную, **рекомендуется внедрить систему push-уведомлений**

В городах Казань, Красноярск, Краснодар, Саратов, Мурманск, Дмитров, Сахалинск, Тольятти - разница по всем критериям статистически не значима

В Сочи статистически значима только конверсия (тестовая выборка уступает контрольной)

В Волгограде статистически значимы только платежи (тестовая выборка уступает контрольной)

В Тюмене статистически значим t-критерий по конверсии в покупку и критерий Манна-Уитни по платежам (тестовая группа превосходит контрольную), **рекомендуется внедрить систему push-уведомлений**

В городах Новосибирск, Великий новгород, Нижний Новгород, Ростов-на-Дону, Ростов Великий, Петрозаводск, Чехов, Ярославль есть пустые группы, **требуется больше наблюдений**

### <br>**Определение исхода эксперимента для каждой торговой точки:**

По значению p_value для t-теста и разнице между средними платежами тестовой и контрольной группы, для каждой торговой точки были определены три возможных исхода по внедрению системы push-уведомлений: положительный, отрицательный и нейтральный, если для разница выплат между группами статистически не значима.

Всего - **51** торговая точка (за исключением тех, где не было заплачено ни одного рубля ни одним клиентом)

Положительный исход - **17** т.т.
Отрицательный исход - **3** т.т.
Нейтральный исход - **31** т.т.

### <br>**Калькулятор**

Выгрузив итоговую таблицу в Excel и разбив её по трём исходам, мы построили калькулятор, который по количество клиентов N и минимальному детектируемому эффекту MDE (минимальная разница в среднем чеке в рублях, которую мы заинтересованы обнаружить) высчитывает рост выручки на торговых точках с положительным исходом и падение - на торговых точках с отрицательным исходом, после чего их разницу записывает в *Баланс*.

<img width="307" height="220" alt="image" src="https://github.com/user-attachments/assets/6b10f11f-c8a3-48ee-a102-e3ff9016181e" />

Как видим, наш баланс значительно возрос, введение системы push-уведомлений пошло на пользу, однако рекомендуется делать это не во всех городах, а также добавить наблюдения для т.т. с нейтральным исходом.

Для определения минимального необходимого количества наблюдений по каждой торговой точки из нейтрального исхода также был организован рассчёт в калькуляторе по формуле:<br>
*n = 16 × σ ^ 2 / (MDE ^ 2)*, где σ -  стандартное отклонение по размерам платежей
