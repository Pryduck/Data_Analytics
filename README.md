# Портфолио проектов по аналитике данных

Привет! В этом репозитории собраны мои проекты, связанные с анализом данных. 
Ниже — список проектов и соответствующих им веток.

## Проекты

| Ветка | Проект | Сфера | Инструменты |
|-------|--------|-------|-------------|
| [`SkyCrossroads`](#) | Анализ операционных аномалий и эффективности маркетинговой акции в розничной сети | Retail | Excel, Google Sheets (QUERY, сводные таблицы, дашборды) |
| [`SkyLenta`](#) | A/B-тест пуш-уведомлений vs баннеров в мобильном приложении SkyLenta | E-commerce | Python (pandas, numpy, matplotlib/seaborn), статистика (t-тест, Манна-Уитни), Excel |
| [`SkySport`](#) | Анализ клиентской базы и удержания в сети SkySport | Фитнес | Python (pandas, numpy, matplotlib, seaborn), когортный анализ, LTR/LT |
| [`ZombieRevolution`](#) | Анализ пользовательской активности и вирусного роста в игровом приложении | GameDev | PostgreSQL (CTE, JOIN, агрегации), Excel |

## Что где лежит

- **README внутри каждой ветки** — описание проекта: цель, задачи, этапы, инструменты, результаты и выводы.
- **Файлы с кодом** — Jupyter Notebook (`.ipynb`) или SQL-скрипты, в зависимости от проекта.
- **Таблицы и расчёты** — Excel/Google Sheets файлы с промежуточными и итоговыми расчётами.
- **Презентации** — в проектах, где требовалась защита результатов.
